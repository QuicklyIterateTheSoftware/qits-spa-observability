What this is

qits-observability receives OTLP from every service on this platform and keeps it in memory. There is no database behind it, no file on disk, and no retention policy — the store empties completely every time the service restarts, and a deploy of qits-observability is a restart. That is the design, not a gap: this is a live buffer for looking at what is happening now, and it was never meant to answer questions about last week.

It is also bounded. Each source holds at most {{ caps() }}; past that the oldest records are evicted to make room, so what you read here is what survived rather than everything that ever arrived. @if (hasEvicted()) { Eviction is active on this process — the band above says how much it has taken. }

Two consequences worth knowing before you read anything below. An empty screen after a restart is correct and says so. And a trace id that answers with nothing may have been evicted rather than never have existed — the service answers both the same way, and this UI will not guess between them.
